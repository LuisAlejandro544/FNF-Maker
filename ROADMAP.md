# Roadmap — BeatForge Studio

Hoja de ruta técnica y de producto para **BeatForge Studio** (`com.beatforge.studio`).

---

## Fase 1 — Núcleo Rust Modular, Audio AAudio Puro, UI Jetpack Compose y CI Manual 32/64 bits (Actual)

- [x] **Workspace Rust modular (`/engine`)**:
  - `pulse_core`: Parser y exportador completo de `chart.json` (`player1`, `player2`, `gfVersion`, `stage`, `events`, `changeBPM`, `mustHitSection`, `gfSection`, `cameraSlot`, `-1` inline, **`parse_chart_camera_event`** para `FocusCamera`/`ZoomCamera`/`Camera Follow Pos`/`Add Camera Zoom`/`Switch Camera`/`Camera Movement` y **`NoteSpecialKind`** para notas normales, `hurt` X, `instakill` X, `dodge`, `alt` y `no_anim`), decodificador **`.astc`** (`texture2ddecoder`) y codificador **WebP sin pérdida (VP8L)** puro Rust con **dithering Floyd-Steinberg `RGB_565` (`TexturePixelFormat::Rgb565`) y cuantización perceptual `exoquant` 0.2.0 (MIT)** en `astc_loader.rs`, ensamblador Sparrow `.xml` (`page_index`) + atlas **`.json`** (`TexturePacker`/`Aseprite`, `spritemap1.json`, `Animation.json` con poses `Idle`, direcciones, `Miss` y **`DeathStart` / `DeathLoop` / `DeathConfirm`** + **`normalize_and_center_animations()`** por defecto), **`mod_descriptors.rs`** (descriptores `.json`/`.xml` de personaje y escenario Psych/V-Slice/Codename), escena `1280×720` con **sistema multicámara (`Cam 0` Fija inicial, `Cam 1` Jugador, `Cam 2` Enemigo, `Cam 3+` personalizadas + límites de cámara contra fondo `clamp_to_background`)**, auto-dimensionado inteligente (`fit_dimensions_to_atlas` / `fit_dimensions_to_image`), Z-order, cámara bidireccional (`camera_system.lua` V2), plantilla sincronizada `stage_events.lua`, **`svg_skin.rs`** (`resvg` + `hurt_x.svg` + `import_arrow_sparrow_atlas` para `NOTE_assets.png + .xml`), **`gfx_backend.rs`** (tipos `RenderBackendKind` y `GfxCapabilities` para Canvas2D / GLES2 / GLES3 / Vulkan), `script_optimizer.rs`, **`atlas_repack.rs`** (`crunch`, recorte alfa, neutralización de `_p1.._p5.webp`), **`hot_compile`** (esquema **v6** con **mip-downscale `Lanczos3` al tamaño físico de pantalla + zoom máximo de cámara** y **Plan de Pre-carga Temporal por Eventos   - `pulse_audio`: Mezclador lock-free de hasta 3 pistas sincronizado por muestras en **Rust puro** (`libaaudio.so` vía `dlopen` con **`probe_aaudio_hardware()`** para sondeo de tasa/burst/baja latencia/canal, cero C++), decodificadores permisivos (`lewton`, `hound`, `rmp3` con feature `float`) con **ruta nativa `f32` + `rubato::FftFixedIn`** (`decode_audio_file_raw_f32` sin `resample_stereo_linear`) y PCM `i16` compacto en el editor, **caché binario `.bfaud` (`audio_cache.rs`)** en `cacheDir/audio_cache/` con escritura atómica y LRU, **fusión en caliente de 1–3 pistas a WAV único + streaming SPSC de 512 KB** (`streaming.rs`) y paso **lineal sin `tanh()`** para `stream_source` en `mixer.rs`, **Adaptador Acústico Adaptativo `f32` (`adaptive_master.rs`)** con **`ebur128`** (LUFS/LRA/True Peak), **`realfft` + `rustfft`** (espectro 5 bandas con ventana Hann), **`biquad` (`DirectForm2Transposed`)**, **`rubato` (`FftFixedIn`)**, **anchura estéreo Mid/Side + crossfeed psicoacústico ligero (700 Hz / 0.25 ms)**, **limitador Lookahead 4 ms + envolvente suave (~65 ms)**, **dither TPDF ±1 LSB** y caché `audio_adapted/` (`v2`), **cuenta regresiva BPM ("3, 2, 1, ¡YA!")** y **síntesis Game Over (`DeathStart` / `DeathConfirm`)** lock-free.

  - `pulse_android`: Puente JNI (`EngineSession`) modularizado (`editor_ops` con gestión de ranuras `Cam 0..3+`, `clamp_to_background`, `section.cameraSlot` y `set_audio_adapt_enabled`, `sprite_ops` con auto-escalado proporcional al importar imagen/atlas y `page_index`, `persistence_ops` con normalización automática de atlas y limpieza de cachés al cargar/crear/borrar proyectos, **`gfx_probe.rs`** por `dlopen`, `gameplay_ops` con **`hot_compile_with_viewport`**, **`audio_adapt_ops.rs`** independiente antes de gameplay, drenaje automático de colas **`timeline_preload_queue` / `timeline_retire_queue`**, multicámara, clamping contra fondo y eventos directos de `chart.json`) + estados lock-free **`HOT_COMPILE_PROGRESS`** y **`AUDIO_ADAPT_PROGRESS`**, reporte **`repacked_entity_ids` / `compiled_texture_pages` / `texture_pixel_formats` / `timeline_windows`**, staging temporal en `cacheDir`, adopción en `filesDir/projects/<id>/assets/`, caché multi-proyecto LRU `compiled_cache/<projectId>/`, precarga `4000 ms` + retiro `1500 ms`, **`GameOver` completo (`DeathStart -> DeathLoop -> DeathConfirm`)**, **Botplay / Modo Práctica**, notas especiales `Hurt`/`Instakill`/`Dodge`/`Alt`/`NoAnim` y paquete binario **`BFGP` v2 (`152B`)** extendido con bits `9..13` (`gameOver`, `gameOverPhase`, `botplay`, `practiceMode`), **bits `8..15` de `e_flags` (`page_index`)** y bits `4..7` de `noteFlags` (`noteKindCode`).
- [x] **Interfaz Android Nativa en Kotlin + Jetpack Compose (`/android`)**:

## Fase 2 — Empaquetado de Mods, Notas Especiales, Game Over y Terreno GPU (Completado)

- [x] **Exportador e Importador de Paquetes `.mod` (Contenedor Vanilla + Zstd)**:
  - Contenedor propio **Vanilla** (`VNLA` v1) con compresión **Zstandard (`zstd`)** en streaming 64 KB, conversión inteligente PNG→WebP lossless VP8L, deduplicación, FNV-1a 64-bit e integración SAF completa en `ProjectsScreen`.
- [x] **Offsets por Frame, Centrado Universal de Sprites, Auto-Tamaño de Escenario y Skins `NOTE_assets`**:
  - Descriptores `characters/*.json|xml` y `stages/*.json|xml`, centrado automático por defecto de todos los formatos de spritesheets (`Sparrow .xml`, TexturePacker/Aseprite `.json`, `spritemap1.json`, `Animation.json`), ajuste proporcional `1280×720` al importar sprites en escenario, `Offset Pose X / Y` en vivo, importación 2 pasos `NOTE_assets.png + .xml` y flecha especial SVG marcada con **"X"** para notas peligrosas.
- [x] **Lobby Inicial de Proyectos, Game Over Interactivo y Pausa Debug**:
  - Menú principal al arrancar + pantalla dedicada `ProjectLoadingScreen`, ciclo Game Over estilo FNF (toque en personaje o pantalla para reintentar) y panel Debug en Pausa (RAM, FPS, Botplay, Práctica, HUD oculto).

## Fase 3 — Renderizador Acelerado GPU (OpenGL ES 2.0/3.x y Vulkan) y Comunidad

- [x] **Sistema Multicámara Profundo y Seguimiento Directo desde `chart.json`**:
  - `Cam 0` (Fija inicial hasta recibir acciones), `Cam 1` (Jugador), `Cam 2` (Enemigo) y `Cam 3+` personalizadas (`Fijo`, `Jugador`, `Enemigo`, `GF`, `Entidad`), con FOV/zoom y suavizado por ranura, selector de cámara por sección en el Chart (`section.cameraSlot`), pestaña `"Cámara"` en `ChartStepCueDialog` y ejecución directa de `FocusCamera` (V-Slice), `ZoomCamera`, `Camera Follow Pos`, `Add Camera Zoom`, `Switch Camera` y `Camera Movement` (Codename).
- [x] **Editor Visual de Timeline `#` y `stage_events.lua` (Swaps, Flashes y Personajes)**:
  - Columna interactiva `#` en `ChartScreen` (`ChartStepCueDialog`) y script `stage_events.lua` para swaps, liberación/precarga RAM, flashes y cambios de personaje por paso.
- [x] **API Extendida Sin Ataduras y Terreno Base GLES 2.0/3.x + Vulkan**:
  - Gráficos/textos dinámicos (`makeText`, `makeHudGraphic`, `makeGraphic`), multicámara (`switchCamera`, `setCameraFollowPos`, `clearCameraFollowPos`, `getActiveCamera`, `getGfSection`), flashes, ciclo RAM, tweens, Game Over (`triggerGameOver` / `onGameOver`) y capa de sondeo + arquitectura `gfx/` lista para conectar renderizado GPU nativo.
- [ ] **Renderizador GPU Activo (`GLES 2.0 / GLES 3.x` + `Vulkan`)**:
  - Implementar pipelines de texturas y batching por GPU sobre `GlesSurfaceHost` / `Vulkan` aprovechando el terreno y sondeo ya integrados en `gfx_backend.rs` y `gfx_probe.rs`.
- [ ] **Reproducción de SFX desde Scripts y Calibrador de Latencia AAudio**:
  - API `playSound` para efectos cortos desde Lua/TS/JS y asistente rápido de golpeteo al ritmo para calcular `audio_offset_ms` óptimo.
